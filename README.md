# Ashsmith

Action roguelite per telefono con una forgia dentro la partita. Fatto con Godot 4.5.

- **Gioca dal telefono:** https://iarussodavide28-cyber.github.io/ashsmith/
- Il codice è nel ramo `main`; la versione web pubblicata è nel ramo `gh-pages`.

## Come si costruisce la versione web

```
./tools/build_web.sh   # esporta in build/web con Godot 4.5.1
```
